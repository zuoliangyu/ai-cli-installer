## 浏览器

最终 Chromium 场景 3/3 通过，无未捕获 JavaScript 错误：

1. **真实后端与真实安装**：点击安装 Codex Native；双击只产生一次 POST；刷新时任务仍为 `running`，恢复同一任务；安装成功后显示正确版本、Native 来源和安装路径；切换页面再返回仍显示正确结果。
2. **模拟任务 API**：下载失败提示、改用自动模式重试、移除失败来源限制、恢复成功反馈。
3. **模拟任务 API**：轮询 503 时禁止新安装、恢复连接、刷新恢复活动任务、后端会话变化提示。唯一 console error 是此场景预期注入的 503。

曾观察到成功提示出现时卡片短暂显示“未安装”。增强断言后确认这是异步诊断更新：最终一轮在成功提示后约 812 ms 更新完成，独立 `/api/tools` 检查的版本、来源和路径一致。此数值是单次观测，不是性能保证。

## 初次失败与修正

测试开发过程中修正了三类脚本错误：把具体版本误填进发布渠道参数、同名“关于”标题造成定位歧义，以及页面刷新后读取旧页面轮询响应。修正后只复测受影响的 Codex Native 和浏览器场景，保留首轮失败日志，未将失败结果隐藏为成功。

测试入口同时处理了 PowerShell 版本约束、子进程被信号终止时的等待、镜像与磁盘源码不一致、固定镜像 ID 运行和本次容器清理。
